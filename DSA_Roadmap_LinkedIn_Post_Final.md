# 🚀 DSA Roadmap for Beginners

Starting Data Structures & Algorithms can feel overwhelming when you don’t know what to learn first.

Here’s a simple roadmap to help you move step by step — from programming basics to interview preparation:

## 1️⃣ Programming Basics
- Time & Space Complexity
- Recursion
- Basic Problem Solving
- C++ / Java / Python

## 2️⃣ Arrays & Strings
- Traversal
- Sorting
- Two Pointers
- Sliding Window
- Prefix Sum
- Kadane's Algorithm

## 3️⃣ Hashing
- Hash Map
- Hash Set
- Frequency Counting
- Anagrams
- Common Applications

## 4️⃣ Linked Lists
- Singly & Doubly Linked Lists
- Fast & Slow Pointers
- Reversal
- Merge
- Cycle Detection

## 5️⃣ Stacks & Queues
- Stack
- Queue
- Deque
- Monotonic Stack
- Priority Queue
- Applications

## 6️⃣ Binary Search
- Standard Binary Search
- Rotated Arrays
- Lower Bound / Upper Bound
- Search on Answer

## 7️⃣ Trees & BST
- Tree Traversals
- DFS
- BFS
- BST
- LCA
- Height & Depth

## 8️⃣ Graphs
- BFS
- DFS
- Shortest Path
- Topological Sort
- Union-Find
- Cycle Detection

## 9️⃣ Backtracking
- Subsets
- Combinations
- Permutations
- N-Queens
- Pruning
- Constraint Problems

## 🔟 Dynamic Programming
- Memoization
- Tabulation
- Top-Down / Bottom-Up
- Knapsack
- LIS / LCS

> 💡 The goal is not to memorize solutions. Understand the pattern, solve problems, and gradually build your problem-solving skills.
