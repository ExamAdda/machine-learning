# 🚀 DSA Roadmap for Beginners

A simple path from programming basics to interview preparation.

**Learn → Practice → Solve → Grow**

---

## 📚 DSA Roadmap

### 01. Programming Basics
- Time & Space Complexity
- Recursion
- Basic Problem Solving
- C++ / Java / Python

### 02. Arrays & Strings
- Traversal
- Sorting
- Two Pointers
- Sliding Window
- Prefix Sum
- Kadane's Algorithm

### 03. Hashing
- Hash Map
- Hash Set
- Frequency Counting
- Anagrams
- Common Applications

### 04. Linked Lists
- Singly & Doubly Linked Lists
- Fast & Slow Pointers
- Reversal
- Merge
- Cycle Detection

### 05. Stacks & Queues
- Stack
- Queue
- Deque
- Monotonic Stack
- Priority Queue
- Applications

### 06. Binary Search
- Standard Binary Search
- Rotated Arrays
- Lower Bound / Upper Bound
- Search on Answer

### 07. Trees & BST
- Tree Traversals
- DFS
- BFS
- BST
- LCA
- Height & Depth

### 08. Graphs
- BFS
- DFS
- Shortest Path
- Topological Sort
- Union-Find
- Cycle Detection

### 09. Backtracking
- Subsets
- Combinations
- Permutations
- N-Queens
- Pruning
- Constraint Problems

### 10. Dynamic Programming
- Memoization
- Tabulation
- Top-Down / Bottom-Up
- Knapsack
- LIS / LCS

> Don't just memorize solutions. Understand the pattern behind the problem.

**Learn the concept → solve problems → recognize patterns → improve**
