# machine-learning-interview
1. What is Machine Learning?
 
Answer:

Machine Learning is a branch of Artificial Intelligence that allows computers to learn from data and make predictions or decisions without being explicitly programmed for every task.
Example: A spam filter learns from previous emails and predicts whether a new email is spam or not.

2. What are the types of Machine Learning?
   
Answer:

There are three main types of Machine Learning:

(I) Supervised Learning – learns from labeled data.

(II) Unsupervised Learning – finds patterns in unlabeled data.

(III) Reinforcement Learning – learns through rewards and penalties.

Example:
Predicting house prices → Supervised Learning
Grouping customers → Unsupervised Learning


3. What is the difference between Classification and Regression?

Answer:

Classification is used to predict a category or class.
Example:

Spam / Not Spam
Pass / Fail

Regression is used to predict a continuous numerical value.
Example:

House price
Salary
Temperature

Simple way to remember:
Classification → Category
Regression → Number

4. What is Overfitting?
   
Answer:

Overfitting happens when a machine learning model learns the training data too well, including its noise, and performs poorly on new, unseen data.
For example:
Training accuracy → 98%
Testing accuracy  → 65%
This indicates the model may be overfitting.

Ways to reduce overfitting:

 Use more training data
 
 Use regularization
 
 Use cross-validation
 
 Simplify the model


5. What is the difference between Training Data and Testing Data?

Answer:

Training data is the data used to train and learn the model.

Testing data is unseen data used to evaluate how well the trained model performs.

Example:

Dataset
   ↓
80% → Training → Learn
20% → Testing  → Evaluate

The important point is that testing data should not be used to train the model.
